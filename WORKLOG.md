### BUG-1 (observed) — logged-out session cookie still accepted

- Hypothesis: iron-session seals the session into the cookie itself; `session.destroy()` only tells the browser to drop it, the server keeps no revocation state. Checked `src/server/auth/current-user.ts`: validity = decrypt OK + user enabled + `sessionVersion` match; logout did not change `sessionVersion`, so the copy still matched.
